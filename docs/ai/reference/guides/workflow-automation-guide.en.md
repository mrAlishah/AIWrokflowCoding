# Workflow Automation Guide

## Purpose

This guide explains the supported automation-style prompts for PBI, review, and PR review workflows.

These prompts are designed for end users who want one clear starting point with the minimum required inputs.

## Important Rule

V2.3 does not allow free-form execution of many skills in one prompt.

Supported automation means:

- PR review can run end-to-end through the single approved `pr_review_workflow` skill.
- PBI and lower-level review use launcher prompts that execute the first skill and prepare the next prompt.

## Prompt Map

| Workflow | Prompt | Behavior |
|---|---|---|
| PBI workflow | `docs/ai/reference/prompts/pbi/00-pbi-workflow-launcher.prompt.md` | Starts with `pbi_clarification` and prepares the next prompt. |
| Review workflow | `docs/ai/reference/prompts/review/00-review-workflow-launcher.prompt.md` | Starts with `review_workspace_create` and prepares the next prompt. |
| PR review workflow | `docs/ai/reference/prompts/pr/00-pr-review-all-in-one.prompt.md` | Runs the full local PR/code review through `pr_review_workflow`. |

## When To Use Each Prompt

Use the PBI launcher when the input is a raw feature request, user story, or backlog item.

Use the review launcher when you want manual control over each lower-level review step.

Use the PR review all-in-one prompt for the normal daily local PR/code review.

## How To Run

1. Open the matching prompt.
2. Replace parameter values only.
3. Run the prompt.
4. Read the output.
5. If the prompt provides a next prompt, review it before running it.

## Safety Rules

- Do not ask PBI or review launchers to execute every workflow step automatically.
- Do not modify source code during review-only work.
- Do not call PR APIs during local review.
- Do not read all docs, all skills, or the whole repository.
- Keep each run tied to one selected skill.

## Recommended Daily Use

For feature delivery:

```text
00-pbi-workflow-launcher.prompt.md
-> next prompt generated by the agent
-> continue one skill at a time
```

For daily PR review:

```text
00-pr-review-all-in-one.prompt.md
```

For controlled review steps:

```text
00-review-workflow-launcher.prompt.md
-> next prompt generated by the agent
-> continue one review skill at a time
```
