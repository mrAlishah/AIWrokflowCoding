# راهنمای automation workflow

## هدف

این راهنما promptهای automation-style پشتیبانی‌شده برای PBI، review و PR review را توضیح می‌دهد.

این promptها برای کاربری هستند که می‌خواهد با کمترین ورودی لازم، یک نقطه شروع روشن داشته باشد.

## قانون مهم

در V2.3 اجرای آزاد چند skill در یک prompt مجاز نیست.

automation پشتیبانی‌شده یعنی:

- PR review می‌تواند از طریق skill واحد و رسمی `pr_review_workflow` به‌صورت end-to-end اجرا شود.
- PBI و review سطح پایین‌تر از launcher prompt استفاده می‌کنند؛ launcher فقط skill اول را اجرا می‌کند و prompt مرحله بعد را آماده می‌کند.

## نقشه promptها

| Workflow | Prompt | رفتار |
|---|---|---|
| PBI workflow | `docs/ai/reference/prompts/pbi/00-pbi-workflow-launcher.prompt.md` | با `pbi_clarification` شروع می‌کند و prompt مرحله بعد را آماده می‌کند. |
| Review workflow | `docs/ai/reference/prompts/review/00-review-workflow-launcher.prompt.md` | با `review_workspace_create` شروع می‌کند و prompt مرحله بعد را آماده می‌کند. |
| PR review workflow | `docs/ai/reference/prompts/pr/00-pr-review-all-in-one.prompt.md` | review کامل local PR/code را از طریق `pr_review_workflow` اجرا می‌کند. |

## چه زمانی از هر prompt استفاده کنم

وقتی ورودی شما feature request، user story یا backlog item خام است، از PBI launcher استفاده کن.

وقتی می‌خواهی روی هر مرحله review کنترل دستی داشته باشی، از review launcher استفاده کن.

برای review روزانه local PR/code، از PR review all-in-one استفاده کن.

## نحوه اجرا

1. prompt مناسب را باز کن.
2. فقط مقدار parameterها را تغییر بده.
3. prompt را اجرا کن.
4. خروجی را بخوان.
5. اگر agent prompt مرحله بعد را آماده کرد، قبل از اجرا آن را بررسی کن.

## قوانین ایمنی

- از PBI یا review launcher نخواه همه مرحله‌های workflow را خودکار اجرا کند.
- در کار review-only source code را تغییر نده.
- در local review از PR API استفاده نکن.
- همه docs، همه skillها یا کل repository را نخوان.
- هر اجرا باید به یک skill انتخاب‌شده محدود باشد.

## استفاده روزانه پیشنهادی

برای feature delivery:

```text
00-pbi-workflow-launcher.prompt.md
-> next prompt generated by the agent
-> continue one skill at a time
```

برای daily PR review:

```text
00-pr-review-all-in-one.prompt.md
```

برای review مرحله‌ای و کنترل‌شده:

```text
00-review-workflow-launcher.prompt.md
-> next prompt generated by the agent
-> continue one review skill at a time
```
