# Tools Skills

Canonical path:

```text
docs/ai/skills/tools/
```

## Naming

Tool skill files use the `tools_*` prefix.

## Skills

- `tools_system_health_check`: audit AI Operating System health.
- `tools_reference_update`: maintain user-facing `docs/ai/reference/` guides and prompts.
- `tools_repo_context_update`: refresh reusable repository knowledge.
- `tools_policy_plan_update`: synchronize approved policy or planning input.
- `tools_docs_ai_cleanup_audit`: audit `docs/ai` cleanup and context cost.

## Compatibility

Old invocation names are mapped in `docs/ai/skills/README.md`.
