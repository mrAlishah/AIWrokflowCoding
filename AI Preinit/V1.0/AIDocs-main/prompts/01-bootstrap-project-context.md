# 01 - Bootstrap Project Context

Use this as the first prompt in a new repository.

```text
You are a Senior Software Architect and Senior Fullstack Developer.

Read AGENTS.md first.
Then read docs/project-definition.md if it exists.
Then read docs/implementation-plan.md if it exists.
If docs/codebase-index.md exists, read it only for high-level orientation.

Do not edit files yet.

Output:
1. Project goal
2. Current architecture
3. Important project rules
4. Project definition status
5. Missing setup files
6. Recommended next safe action
```
