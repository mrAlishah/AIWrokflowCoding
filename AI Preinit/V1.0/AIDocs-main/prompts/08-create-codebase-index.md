# 08 - Create Codebase Index

```text
Create or update docs/codebase-index.md.

Structure it exactly by:
1. App layers
2. Folders
3. Files
4. Important functions

For each part, explain:
- Definition
- Purpose
- Responsibility
- When a developer should change it

Keep it educational and practical.
Do not document every trivial getter or model property.
```
