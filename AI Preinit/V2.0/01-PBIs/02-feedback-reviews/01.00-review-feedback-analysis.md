## Parameters

| Parameter         | Required    | Options                                      | توضیح                                  |
| ----------------- | ----------- | -------------------------------------------- | -------------------------------------- |
| `PBI_ID`          | Yes         | `STP-XXXX`                                   | شناسه PBI موجود                        |
| `INPUT_MODE`      | Optional    | `prompt`, `file`, `existing-review-feedback` | محل دریافت commentها                   |
| `REVIEW_FEEDBACK` | Conditional | text                                         | وقتی `INPUT_MODE: prompt` است لازم است |
| `ANALYSIS_DEPTH`  | Optional    | `light`, `normal`, `deep`                    | عمق تحلیل AI                           |

## ANALYSIS_DEPTH Options

| Option   | کاربرد                                                 |
| -------- | ------------------------------------------------------ |
| `light`  | فقط دسته‌بندی سریع commentها                           |
| `normal` | حالت پیشنهادی برای اکثر reviewها                       |
| `deep`   | وقتی commentها معماری، security یا behavior حساس دارند |
