## Parameters

| Parameter     | Required | Options                 | توضیح                 |
| ------------- | -------- | ----------------------- | --------------------- |
| `PBI_ID`      | Yes      | `STP-XXXX`              | شناسه PBI             |
| `RF_ID`       | Yes      | `RF-001`, `RF-002`, ... | RF مورد بررسی         |
| `REVIEW_MODE` | Optional | `normal`, `strict`      | میزان سخت‌گیری review |

## REVIEW_MODE Options

| Option   | کاربرد                                                                          |
| -------- | ------------------------------------------------------------------------------- |
| `normal` | بررسی معمولی fix                                                                |
| `strict` | پیشنهاد شده برای post-PR feedback، چون باید مطمئن شوی comment همکار درست حل شده |

## خروجی مورد انتظار

اگر fix کامل بود:

```
RF status -> Done
```

اگر کامل نبود:

```
RF status -> Required
```

اگر نیاز به تصمیم بیشتر داشت:

```
RF status -> Blocked
```
