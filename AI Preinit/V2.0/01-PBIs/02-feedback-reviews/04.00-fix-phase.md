## Parameters

| Parameter   | Required | Options                                      | توضیح                 |
| ----------- | -------- | -------------------------------------------- | --------------------- |
| `PBI_ID`    | Yes      | `STP-XXXX`                                   | شناسه PBI             |
| `RF_ID`     | Yes      | `RF-001`, `RF-002`, ...                      | شناسه review feedback |
| `FIX_SCOPE` | Optional | `required-only`, `required-and-safe-cleanup` | محدوده fix            |

## FIX_SCOPE Options

| Option                      | کاربرد                         |
| --------------------------- | ------------------------------ |
| `required-only`             | فقط fix همان RF؛ حالت پیشنهادی |
| `required-and-safe-cleanup` | fix + cleanup کوچک و کم‌ریسک   |

## قانون مهم

Skill باید خودش این‌ها را resolve کند:

```
RF_ID -> review-feedback.md -> RF file -> source files
```

تو نباید مسیر فایل RF را در prompt بنویسی.
