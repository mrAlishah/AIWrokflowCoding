## Parameters

| Parameter   | Required | Options                | توضیح                                    |
| ----------- | -------- | ---------------------- | ---------------------------------------- |
| `SCOPE`     | Yes      | `pbi`                  | این تغییر فقط برای همین PBI است          |
| `STP_ID`    | Yes      | `STP-XXXX`             | شناسه PBI                                |
| `INPUT_TAG` | Yes      | `USER_REVIEW_FEEDBACK` | یعنی تصمیم‌های User درباره RFها sync شود |

## این Skill خودش چه کار می‌کند؟

Skill خودش مسیرها را پیدا می‌کند:

```
phases/review-feedback.md
phases/RF-*.md
02-implementation-plan.md
03-codebase-index.md
04-decision_log.md
```

نیازی نیست تو path بدهی.
