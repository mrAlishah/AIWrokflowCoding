# مرحله 2 — تصمیم User درباره RFها

بعد از تحلیل AI، فایل زیر را باز کن:

```
docs/ai/pbi/STP-1234/phases/review-feedback.md
```

برای هر RF یکی از این Statusها را انتخاب کن:

```
Required
Ignored
Blocked
```

مثال:

```markdown
### RF-001

Title:
Missing null validation

Status:
Required
```

یا:

```markdown
### RF-002

Title:
Optional naming cleanup

Status:
Ignored
```

قانون:

```
AI حق ندارد خودش RF را Required کند.
Required یعنی User تأیید کرده باید fix شود.
```
