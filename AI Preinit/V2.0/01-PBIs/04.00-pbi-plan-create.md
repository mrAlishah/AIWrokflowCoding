### Parameters

| Parameter      | Required | توضیح                 |
| -------------- | -------- | --------------------- |
| PBI_ID         | Yes      | شناسه PBI             |
| PLANNING_DEPTH | Optional | میزان عمق برنامه‌ریزی |

### PLANNING_DEPTH Options

| Option | کاربرد                                                  |
| ------ | ------------------------------------------------------- |
| light  | فقط Phaseهای اصلی، سریع‌ترین Planning ممکن              |
| normal | حالت پیش‌فرض، مناسب اکثر PBIها                          |
| deep   | تحلیل عمیق‌تر، Dependencyها، ریسک‌ها و Planning کامل‌تر |

### Rules

| Rule                      | توضیح                       |
| ------------------------- | --------------------------- |
| Read Repo Context First   | ابتدا repo-context          |
| Limited Source Inspection | فقط در صورت نیاز سورس بخوان |
| No Implementation         | فقط Planning                |
