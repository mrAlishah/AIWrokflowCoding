### Parameters

| Parameter   | Required | توضیح                 |
| ----------- | -------- | --------------------- |
| PBI_ID      | Yes      | شناسه PBI             |
| PHASE       | Yes      | فاز مورد بررسی        |
| REVIEW_MODE | Optional | میزان سخت‌گیری Review |

### REVIEW_MODE Options

| Option | کاربرد                                                      |
| ------ | ----------------------------------------------------------- |
| normal | بررسی استاندارد و متعادل                                    |
| strict | بررسی سخت‌گیرانه‌تر روی معماری، کیفیت، Validation و ریسک‌ها |

### Rules

| Rule              | توضیح                    |
| ----------------- | ------------------------ |
| No Source Changes | کد را تغییر نده          |
| Findings Only     | فقط Findings و پیشنهادها |
