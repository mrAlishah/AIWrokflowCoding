### REVIEW_SCOPE Options

| Option                 | Description   |
| ---------------------- | ------------- |
| full                   | Full review   |
| backend-only           | Backend only  |
| frontend-only          | Frontend only |
| tests-only             | Tests         |
| security-sensitive     | Security      |
| architecture-sensitive | Architecture  |

Parameters:

```
STP_ID
BASE_BRANCH
CURRENT_BRANCH
PR_TITLE
PR_DESCRIPTION
REVIEW_SCOPE
```
